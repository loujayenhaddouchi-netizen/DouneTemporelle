DouaneTemporelle

### Mini-projet de Programmation Mobile

**Réalisé par :**
- **Loujayen Haddouchi**
- **Niveau :** 3ème année Business Intelligence (BI)
- **Groupe :** A03
- **Établissement :** FSEGT – Université de Tunis El Manar

- Présentation

DouaneTemporelle est une application mobile Android qui simule un poste de douane pour les voyageurs temporels.
L'application permet d'enregistrer les informations d'un voyageur, d'analyser sa demande de déplacement dans le temps et de prendre une décision finale : autoriser ou refuser le voyage
